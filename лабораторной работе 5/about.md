**Базовый уровень - табулирование функции:** Программа запрашивает у пользователя начальное значение `a`, конечное значение `b` и шаг `h`, после чего проверяет корректность ввода. С помощью цикла `for` выполняется последовательный перебор значений `x` от `a` до `b` с заданным шагом. Для каждого значения вычисляется функция `y = (x + 1) / (x - 1)`. Отдельно проверяется значение `x = 1`, так как в этой точке функция не определена. Результаты выводятся в виде таблицы с использованием `setw(15)` для выравнивания столбцов.

**Средний уровень - подсчёт целых значений функции:** Программа запрашивает границы интервала и выполняет вычисление функции `y = 2^x` для последовательных значений `x`. С помощью функции `pow()` рассчитывается значение функции, после чего оно сравнивается с ближайшим целым числом с учётом заданной погрешности. Если значение считается целым, увеличивается счётчик. В конце программа выводит количество найденных целых значений функции.

**Продвинутый уровень - вычисление числа e:** Программа вычисляет число `e` с заданной пользователем точностью, используя разложение в ряд `e = 1 + 1/1! + 1/2! + ...`. Для получения очередного члена используется рекуррентная формула, поэтому факториал каждый раз вычислять заново не требуется. Суммирование выполняется до тех пор, пока очередной член ряда больше заданной погрешности. В конце выводятся полученное значение `e`, количество использованных членов ряда и погрешность вычисления.
