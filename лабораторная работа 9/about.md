**Базовый уровень - поиск максимального из двух чисел:**
Программа запрашивает у пользователя два целых числа и считывает их с клавиатуры. Для определения наибольшего числа используется отдельная функция max(int a, int b), которая принимает два числа в качестве параметров и возвращает большее из них. Перед обработкой выполняется проверка корректности ввода. Полученный результат выводится на экран.

**Средний уровень - заполнение массива случайными числами:**
Программа запрашивает у пользователя размер массива, а также минимальное и максимальное значения для генерации случайных чисел. После проверки корректности введённых данных вызывается функция fillRandom(int arr[], int size, int min, int max), которая заполняет массив случайными целыми числами в заданном диапазоне. Для вывода элементов массива используется отдельная функция printArray(). В результате на экран выводится заполненный массив.

**Повышенный уровень - текстовый редактор:**
Программа представляет собой текстовый редактор с меню, позволяющий выполнять различные операции над строкой. Для ввода и вывода текста используются отдельные функции inputText() и printText(). Функция reverseText() изменяет порядок символов строки на обратный, replaceSubstring() выполняет замену указанной подстроки на другую, а countWords() подсчитывает количество слов в тексте. Для управления программой используется меню с оператором switch, позволяющее пользователю выбирать нужную операцию. Также реализована проверка корректности ввода пунктов меню.
