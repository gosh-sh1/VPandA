**Базовый уровень - присвоение переменной куба числа через указатель:**
Программа запрашивает у пользователя целое число и считывает его с помощью оператора cin. Для возведения числа в куб используется функция cube(), которая принимает указатель на целочисленную переменную (int*). Перед изменением значения функция проверяет, что указатель не равен nullptr. Затем с помощью разыменования указателя вычисляется куб исходного числа и результат записывается непосредственно в исходную переменную. После вызова функции программа выводит полученное значение.

**Средний уровень - проверка сортировки массива по возрастанию:**
Программа запрашивает у пользователя пять целых элементов массива и считывает их с помощью оператора cin. Для проверки упорядоченности используется функция isSorted(), которая принимает указатель на первый элемент массива и его размер. Внутри функции проверяется корректность указателя и размера массива. Затем с помощью указателя выполняется последовательный обход элементов: каждый текущий элемент сравнивается со следующим. Если текущий элемент больше следующего, функция возвращает false, поскольку массив не отсортирован по возрастанию. Если все соседние элементы расположены в правильном порядке, функция возвращает true. После проверки программа выводит исходный массив и сообщает, отсортирован ли он по возрастанию. Равные соседние элементы допускаются.

**Повышенный уровень - арифметика указателей void* и побайтовый доступ к памяти:**
Программа создаёт целочисленную переменную и универсальный указатель void*, которому присваивается адрес этой переменной. Сначала программа выводит значение переменной и её адрес. Затем демонстрируется ограничение универсального указателя: выполнять арифметические операции непосредственно с void* нельзя, поскольку размер объекта, на который он указывает, неизвестен. Для побайтового доступа универсальный указатель преобразуется к типу char* с помощью static_cast. После этого с помощью цикла и арифметики указателей программа последовательно обращается к каждому байту памяти переменной. Для каждого байта выводятся его номер, числовое значение и адрес. Размер переменной в байтах определяется оператором sizeof. Таким образом демонстрируется возможность побайтового обхода памяти после преобразования void* в char*.
