**Базовый уровень - обмен значениями двух вещественных переменных:**
Программа запрашивает у пользователя два вещественных числа и считывает их с помощью оператора `cin`. Для обмена значениями используется функция `swap()`, принимающая два параметра по ссылке (`double&`). Сначала значения переменных сохраняются во временную переменную, после чего выполняется их обмен. Перед вызовом функции и после него программа выводит значения переменных на экран, демонстрируя результат обмена.

**Средний уровень - разложение числа на цифры и вычисление их суммы и произведения:**
Программа запрашивает у пользователя целое число и считывает его с помощью оператора `cin`. Для вычисления суммы и произведения цифр используется функция `digitStats()`, которая принимает число и две переменные по ссылке для сохранения результатов. С помощью цикла `while` последовательно извлекаются цифры числа: последняя цифра определяется оператором `% 10`, а само число уменьшается делением на `10`. Каждая извлечённая цифра добавляется к сумме и умножается на текущее значение произведения. В конце программа выводит сумму и произведение цифр исходного числа. Также предусмотрена обработка нуля и отрицательных чисел.

**Повышенный уровень - сортировка массива с подсчётом количества сравнений и обменов:**
Программа запрашивает у пользователя размер массива и его элементы. Для сортировки используется алгоритм пузырьковой сортировки, реализованный в функции `bubbleSort()`. Функция принимает массив, его размер и дополнительные параметры по ссылке, в которых сохраняются количество сравнений, количество обменов и код ошибки. Во время сортировки соседние элементы сравниваются между собой, и если предыдущий элемент больше следующего, они меняются местами с помощью функции `swapInt()`. После завершения сортировки программа выводит отсортированный массив, количество выполненных сравнений и обменов, а также код ошибки. Дополнительно демонстрируются три способа передачи параметров в функцию: по значению, по ссылке и через указатель. Для изменения элемента массива используется функция `getElement()`, возвращающая ссылку на элемент, благодаря чему его значение можно изменить непосредственно через результат вызова функции. Во время ввода проверяется корректность данных и допустимость размера массива.
