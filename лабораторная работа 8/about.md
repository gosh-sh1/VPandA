**Базовый уровень - вывод строки без первого и последнего символа:**
Программа запрашивает у пользователя строку и считывает её полностью с помощью функции `getline()`. С помощью метода `length()` определяется длина введённой строки. Затем проверяется, содержит ли строка не менее двух символов. Если условие выполняется, с помощью метода `substr()` извлекается часть строки, начиная со второго символа и заканчивая предпоследним. Полученная строка выводится на экран. Если строка содержит меньше двух символов, программа выводит соответствующее сообщение.

**Средний уровень - вывод строки с обратным порядком слов:**
Программа запрашивает у пользователя строку и считывает её с помощью функции `getline()`. Для разделения строки на отдельные слова используется класс `stringstream`. С помощью оператора `>>` слова последовательно извлекаются из строки. Каждое новое слово добавляется в начало результирующей строки, а между словами устанавливаются пробелы. Таким образом, порядок слов изменяется на обратный, при этом порядок символов внутри каждого слова сохраняется. В конце программа выводит полученную строку на экран.

**Повышенный уровень - проверка корректности email-адреса:**
Программа запрашивает у пользователя email-адрес и считывает его с помощью функции `getline()`. Сначала проверяется, является ли строка пустой и содержит ли она пробелы. Затем с помощью метода `find()` определяется позиция символа `@`. После этого выполняется поиск точки после найденного символа `@`. Для проверки отсутствия искомых символов используется значение `string::npos`. Если email не пустой, не содержит пробелов, имеет символ `@` и точку после него, программа сообщает, что email корректен. В противном случае выводится сообщение о некорректном email-адресе.
